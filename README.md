# hello-print

This project prints `hello`.

## How to print hello

You need Node.js 18 or later.

From the project root, run:

```sh
npm start
```

You will see one line:

```
hello
```

## How to run the tests

From the project root, run:

```sh
npm test
```

A passing run prints `hello` from the spawn of `cli.js`, then reports both tests as passed.
